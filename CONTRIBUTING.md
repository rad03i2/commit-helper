# Contributing

Contributions are welcome. Keep changes focused, tested, and backward-compatible when practical.

1. Fork and create a feature branch.
2. Use Python 3.10+ and install with `python -m pip install -e . pytest`.
3. Run `pytest -q` and `python -m compileall -q src`.
4. Add tests for behavioral changes.
5. Open a pull request explaining the problem and solution.

Please avoid committing secrets, generated build artifacts, or unrelated formatting changes. By contributing, you agree that your contribution is licensed under the MIT License.
